# Contract: Unix Domain Socket IPC 通信协议规范

**适用范围**: Swift 输入法宿主与 C++ 守护进程之间的进程间通信。

---

## 1. 传输层约束
* **套接字路径**: 固定使用 `$HOME/.local/run/babel.sock`。
* **权限模式**: 文件权限设定为 `0700`（仅当前登录用户有权读写与连接）。
* **协议分帧**:
  * Header: 4 字节，大端整数（Network Byte Order），表示后续 Body 的字节数。
  * Body: UTF-8 编码的合法 JSON 字符串。
  * 最大单包限制: 1 MB（超出则直接切断连接）。

---

## 2. 报文交互时序与语义契约

### 2.1 握手（HELLO）
* 前端连接成功后，**必须**首先发送 `HELLO` 报文。
* 后端返回 `HELLO` 响应，声明守护进程版本与模型就绪状态。

### 2.2 击键事件（KEY_DOWN）
* 当用户在激活的应用内按下物理按键时：
  1. 前端同步发送 `KEY_DOWN`；
  2. 后端在 **1ms** 内完成本地快流判定并返回 `KeyDownResponse`；
  3. 若 `consumed == true`，前端返回 `YES` 拦截按键，并根据 `action` 调用 `setMarkedText` 或准备上屏；
  4. 若 `consumed == false`，前端返回 `NO`，按键交由宿主应用原生处理。

### 2.3 异常与降级契约
* 若后端进程未启动或套接字连接中断：
  * 前端 `handleEvent:client:` **必须**在微秒级立即返回 `NO`（透传按键），不得挂起主线程；
  * 前端后台以指数退避尝试重新连接（初始 500ms，最大 5s）；
  * 降级期间系统输入行为退化为纯英文直通，严禁丢键。
