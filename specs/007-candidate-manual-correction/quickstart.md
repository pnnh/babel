# Quickstart: 候选词列表手动纠偏

**Spec**: [spec.md](./spec.md) ｜ **Plan**: [plan.md](./plan.md)

## 前置条件

```bash
export VCPKG_ROOT=$HOME/vcpkg
export PATH="/opt/homebrew/bin:$PATH"   # macOS；其余平台按既有 CMakePresets.json 配置
cmake --build build/macos --config Debug
cd build/macos && ctest -C Debug --output-on-failure
```

## 验证场景

### 场景一：候选列表展示与"英文优先"默认排序（User Story 1，SC-001/SC-002）

1. 实际运行 `Babel.app`，按全局热键唤起浮窗。
2. 输入拼音 `hen`。
3. **预期**：浮窗输出预览区域下方出现竖排候选列表，第 1 项为英文 `hen`，其余位置按可能性降序展示"很""狠""恨"等拼音候选，编号 1–9 连续不跳号。

### 场景二：数字键手动纠偏（User Story 1，SC-001/SC-002）

1. 延续场景一，候选列表已展示。
2. 按下数字键 `2`。
3. **预期**：1 秒内，原始输入槽中的 `hen` 被替换为候选列表第 2 项对应文本（如"很"）；候选列表随之刷新为替换后文本对应的新候选集合。

### 场景三：数字键超出候选数量时正常插入（FR-012）

1. 输入一个仅产生 3 个候选的词（候选列表显示 1–3 共 3 项）。
2. 按下数字键 `5`。
3. **预期**：数字"5"作为普通字符插入原始输入槽文本，不触发任何候选替换。

### 场景四：候选列表随分隔符切换到新词（User Story 2，SC-003）

1. 输入 `hen `（含尾随空格）。
2. **预期**：候选列表切换为"空白后新词（初始为空）"对应的候选集合或进入无候选可展示状态，不再展示"hen"的候选。
3. 继续输入 `shi`。
4. **预期**：候选列表展示"shi"对应的候选集合，刷新延迟与普通击键后原始输入槽文字更新延迟处于同一量级。

### 场景五：扩展标点作为词边界（FR-005）

1. 输入 `hen,shi`（逗号直接相连，无空格）。
2. **预期**：候选列表在光标经过"hen"时正确展示"hen"的候选集合（而非"hen,"整体回退为无候选的原样透传）；标准中文输出预览中逗号本身正确保留（如"很，是"或等价结果，视默认消歧结果而定）。

### 场景六：候选替换后自动追加分隔符，避免后续拉丁字母被错误合并（第二轮新增，SC-007）

1. 输入 `hen`，候选列表展示。
2. 按下数字键选中"很"。
3. 紧接着继续输入 `bushi`（不手动按空格）。
4. **预期**：原始输入槽文本形如"很 bushi"（自动追加的空格已插入，用户无需手动输入）；候选列表切换为展示"bushi"对应的候选集合（证明"bushi"被正常识别为待纠正拼音 token，未与"很"合并为单一透传 token）。

### 场景七：光标锚定目标词（FR-011）

1. 输入一段中英拼音混排文本，如 `wo hen xihuan ni`。
2. 将光标移动到"hen"内部（而非文本末尾）。
3. **预期**：候选列表切换为展示"hen"对应的候选集合（而非文本末尾词的候选）。

### 场景八：候选列表始终展示，唯一候选编号为"1"（FR-013）

1. 输入一个只会产生单一候选的词（如纯数字"123"）。
2. **预期**：候选列表仍展示，唯一候选编号固定为"1"。

### 场景九：前缀级候选预测（第二轮新增，FR-017/FR-023，SC-006）

1. 输入 `ni`（恰好 2 个字符）。
2. **预期**：候选列表已经展示基于该前缀匹配产出的预测候选（如"你""呢""那""能"等），刷新延迟与整词候选刷新延迟处于同一量级。
3. 输入单个字符 `n`（撤销重来，只输入 1 个字符）。
4. **预期**：候选列表 **MUST NOT** 展示基于该单字符前缀匹配产出的预测候选（除非该单字符本身恰好命中既有完整词形匹配规则，如单字母拼音音节）。
5. 输入英文前缀 `co`（2 个字符）。
6. **预期**：候选列表已经展示英文前缀联想候选（如常见以"co"开头的高频英文词）。

### 场景十：默认不选择候选时行为与交付前一致（FR-015/FR-021，SC-005）

1. 输入一段中英拼音混排内容，候选列表全程展示但不按任何数字键。
2. 按回车确认上屏。
3. **预期**：完整的"击键 → 观察标准中文输出预览渐进坍缩 → 按回车确认上屏"体验与本特性交付前相比，在可感知的行为、延迟与最终上屏结果上没有变化。

### 场景十一：候选列表非输入状态不持续展示（FR-019）

1. 唤起浮窗后点击右上角设置按钮进入设置页面。
2. **预期**：候选列表区域（属主视图子树）随主视图一起不可见。
3. 返回主视图，按 Esc 关闭浮窗。
4. **预期**：候选列表不可见（随整个浮窗一起隐藏）。

### 场景十二：浮窗新尺寸完整容纳 9 项候选（FR-014，SC-004）

1. 输入一个能产生满 9 项候选的拼音（如常见高频音节）。
2. **预期**：浮窗在新默认尺寸下完整展示全部 9 项候选，不发生截断、重叠或遮挡原始输入槽/输出预览/学习提示气泡区域。
